I wanted to build a playful open-source project for Hacktoberfest: something people could explore, enjoy, and improve even if they are new to contributing.

That idea became **The Hollow**, a midnight archive of short horror stories and haunted scenes. Open a random door to reveal a different story. Scroll through the page to see the night shift, and every so often a vampire appears somewhere on screen.

## What’s inside

- Eight original, bite-sized horror stories
- A new SVG scene for each story
- A subtle parallax effect as you scroll the page normally
- Random Count Orlok sightings using locally bundled artwork
- Flying bats, rolling pumpkins, drifting fog, and a foreground spider
- A motion toggle, reduced-motion support, and a responsive layout

The site uses plain HTML, CSS, and JavaScript. There is no build step, package installation, API key, or runtime image service.

## Easy ways to contribute

You can help by:

- Writing a short, original haunting
- Drawing a new SVG scene
- Improving the phone layout, keyboard support, or screen-reader experience
- Fixing a bug or making the project documentation clearer

Before opening a pull request, read the [contribution guide](ADD_YOUR_REPOSITORY_URL/blob/YOUR_DEFAULT_BRANCH/CONTRIBUTING.md). The project is welcoming to contributions year-round.
